# SeekArcTools

Developed by [SeekGene](https://www.seekgene.com/), SeekArcTools is a bioinformatics software suite specifically tailored for processing data from the SeekOne DD Single Cell Multiome (ATAC + RNA) Kit, and also supports standalone analysis of the RNA library within this system. It can process transcriptome and ATAC libraries separately for barcode extraction and correction, read alignment, barcode quantification, cell calling, and the generation of expression matrices, peak matrices, Seurat RDS objects, and analysis reports. The output results can be used for downstream analyses such as clustering and differential analysis; for ATAC + RNA multiome data, they can further support gene-peak association analysis.

## Installation

```bash
git clone https://github.com/seekgene/SeekArcTools.git
cd SeekArcTools
conda env create -f env.yaml
conda activate seekarctools
pip install .
```

## Tutorials

Example 1: ARC multiome analysis

ARC multiome analysis takes both RNA and ATAC FASTQ files as input and performs RNA quantification, ATAC peak calling, joint cell calling, matrix generation, and report generation.

```shell
seekarctools arc run \
    --rnafq1 /path/to/demo/demo_GE_S1_L001_R1_001.fastq.gz \
    --rnafq2 /path/to/demo/demo_GE_S1_L001_R2_001.fastq.gz \
    --atacfq1 /path/to/demo/demo_arc_S2_L002_R1_001.fastq.gz \
    --atacfq2 /path/to/demo/demo_arc_S2_L002_R2_001.fastq.gz \
    --samplename demo \
    --outdir /path/to/outdir \
    --refpath /path/to/reference/GRCh38 \
    --chemistry DD_AG \
    --include-introns \
    --core 16
```

Example 2: Standalone RNA library analysis

Standalone RNA library analysis is used for data containing only the RNA/GEX library. The workflow performs barcode processing, STAR alignment, UMI quantification, cell calling, expression matrix generation, Seurat RDS generation, and GEX quality-control summary output.

```shell
seekarctools rna run \
    --rnafq1 /path/to/demo/demo_GE_S1_L001_R1_001.fastq.gz \
    --rnafq2 /path/to/demo/demo_GE_S1_L001_R2_001.fastq.gz \
    --samplename demo \
    --outdir /path/to/outdir \
    --refpath /path/to/reference/GRCh38 \
    --chemistry DD_AG_RNA \
    --include-introns \
    --core 16
```

Example 3: Adjusting thresholds for re-running peak calling or cell calling

If the peaks or cells identified with the default parameters do not meet requirements, `arc retry` can be used to skip previous steps such as alignment and re-run downstream analysis based on existing intermediate results, saving time while optimizing the results.

```shell
seekarctools arc retry \
    --samplename demo \
    --outdir /path/to/outdir \
    --refpath /path/to/reference/GRCh38 \
    --core 16 \
    --qvalue 0.01 \
    --snapshift 0 \
    --extsize 200 \
    --min_len 200 \
    --min_atac_count 1000 \
    --min_gex_count 500
```

* Note: Ensure that all files generated by the previous run remain intact and have not been deleted or relocated. The `--outdir` parameter should point to the output directory of the original `seekarctools arc run` analysis. The `--min_atac_count` parameter must be used together with `--min_gex_count`; it will not take effect if used alone.

## Parameter descriptions

| Parameter               | Description                                                                                                                                                    |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--rnafq1`              | Path to the R1 FASTQ file of the RNA library                                                                                                                   |
| `--rnafq2`              | Path to the R2 FASTQ file of the RNA library                                                                                                                   |
| `--atacfq1`             | Path to the R1 FASTQ file of the ATAC library                                                                                                                  |
| `--atacfq2`             | Path to the R2 FASTQ file of the ATAC library                                                                                                                  |
| `--samplename`          | Sample name                                                                                                                                                    |
| `--chemistry`           | Chemistry type. Available options for ARC multiome include `DD_AG` and `DD5_AG`; `DD_AG_RNA` is available for standalone RNA library analysis                  |
| `--outdir`              | Output directory. Default: `./`                                                                                                                                |
| `--skip_misB`           | If enabled, no base mismatch is allowed for Barcode; one mismatch is allowed by default                                                                        |
| `--skip_misL`           | If enabled, no base mismatch is allowed for Linker; one mismatch is allowed by default                                                                         |
| `--skip_multi`          | If enabled, reads that can be corrected to multiple whitelist Barcodes are discarded; by default, they are corrected to the Barcode with the highest frequency |
| `--skip_len`            | If enabled, short-read filtering after adapter filtering is skipped, and short reads are retained for downstream analysis                                      |
| `--core`                | Number of threads used for analysis                                                                                                                            |
| `--memory`              | Memory parameter used for Seurat RDS generation in standalone RNA library analysis                                                                             |
| `--include-introns`     | If enabled, intronic reads are also used for gene expression quantification; by default, only exonic reads are used                                            |
| `--refpath`             | Reference genome directory                                                                                                                                     |
| `--star_path`           | External STAR software path. If the reference genome index was built with a specific STAR version, this path can be specified                                  |
| `--scoremin`            | STAR loose-alignment parameter corresponding to `--outFilterScoreMinOverLread`                                                                                 |
| `--matchnmin`           | STAR loose-alignment parameter corresponding to `--outFilterMatchNminOverLread`                                                                                |
| `--pairendAlignment`    | Enable STAR paired-end alignment for standalone RNA library analysis; by default, R2 single-end alignment is used                                              |
| `--pairendMinR1Len`     | Minimum R1 length retained for RNA paired-end alignment. Default: `20`                                                                                         |
| `--expect_cells`        | Expected number of recovered cells in standalone RNA library analysis. Default: `3000`                                                                         |
| `--pvalue`              | p-value threshold for ambient RNA testing in RNA cell calling. Default: `0.01`                                                                                 |
| `--force_cells`         | Force the top N Barcodes ranked by UMI count to be used as cells in standalone RNA library analysis. Default: `0`, indicating automatic cell calling           |
| `--qvalue`              | Minimum FDR q-value cutoff for peak calling. Default: `0.001`                                                                                                  |
| `--nolambda`            | If enabled, MACS3 uses the background lambda as the local lambda and does not consider local bias around candidate peak regions                                |
| `--snapshift`           | Shift size for MACS3 peak calling. Default: `0`                                                                                                                |
| `--extsize`             | Extension size for MACS3 peak calling. Default: `400`                                                                                                          |
| `--min_len`             | Minimum peak length. If not set, it defaults to the value of `extsize`                                                                                         |
| `--broad`               | If enabled, broad peak calling is performed and results are generated in UCSC gappedPeak format                                                                |
| `--broad_cutoff`        | Cutoff for broad peak calling. Default: `0.1`                                                                                                                  |
| `--min_atac_count`      | Cell caller override: minimum number of ATAC transposition events in peak regions for a cell Barcode                                                           |
| `--min_gex_count`       | Cell caller override: minimum number of GEX UMI counts for a cell Barcode                                                                                      |
| `--keep_mito`           | If enabled, mitochondrial reads are retained; by default, mitochondrial reads are filtered out                                                                 |
| `--strict_cell_calling` | If enabled, ambient RNA background testing is added on top of K-Means cell calling to obtain stricter cell calling results                                     |
| `--max_cells`           | Maximum number of automatically called cells; no upper limit is applied if not set                                                                             |
| `-h`, `--help`          | Show the help message                                                                                                                                          |
